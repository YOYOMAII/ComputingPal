# Getting help

For help using ComputingPal, visit the [Help Centre](https://computingpal.com/help). For general questions, use the [Contact page](https://computingpal.com/contact).

To report an issue with this repository or suggest a correction to its public information, open a GitHub issue. The **Public information correction** form asks for the affected file or link, what is wrong, and the expected information.

Keep account details and other private information out of public issues. Use the [Contact page](https://computingpal.com/contact) for those questions.
